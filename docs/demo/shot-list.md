# Shot list

Format: 16:9, 1920 x 1080 export, screen capture at 1440 x 900 scaled, 30 fps, no webcam needed. Total length 3:00 maximum. Audio: one voice-over take, no music bed louder than -30 dB under speech. Captions on (the post autoplays muted on X).

Keep the browser clean: one Chrome window, no bookmarks bar, no personal tabs, wallet extension icon visible only in the testnet take. The Next.js dev indicator (bottom-left "N") appears in `pnpm dev`; hide it by recording a `pnpm build && pnpm start` build, or crop it. Do not run `pnpm build` while a cargo build is running.
